# Power-BI-Dashboard-Project
To develop and design an interactive tenant retention dashboard using Power BI, incorporating Churn Rate and Satisfaction Score statistical models.

## Dataset used
<a href="https://github.com/duval-ys/Power-BI-Dashboard-Project/blob/main/lease_details.csv">dataset</a>

## KPI questions

	What is the current tenant retention rate compared to the previous quarter?

	What is the average satisfaction score of tenants over the last year?

	How does the tenant retention rate impact overall revenue growth?
